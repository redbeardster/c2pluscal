## 🎯 Workflow верификации

```
1. Написать C код
   ↓
2. Транспилировать
   frama-c -pluscal file.c
   ↓
3. Открыть в TLA+ Toolbox
   File → Open Spec
   ↓
4. Транслировать PlusCal
   Ctrl+T
   ↓
5. Создать модель
   TLC Model Checker → New Model
   ↓
6. Добавить инварианты (опционально)
   Invariants → Add
   ↓
7. Запустить проверку
   F11
   ↓
8. Анализ результатов
   ✓ Success / ✗ Error
```

## 📝 Примеры инвариантов

### Пример 1: Проверка результата

```tla
\* Result should be 15 (5 + 10)
ResultCorrect == 
    \/ ~initDone
    \/ \E i \in DOMAIN mem : mem[i] = 15
```

### Пример 2: Безопасность памяти

```tla
\* Stack never overflows
StackSafe == Len(my_stack) < 1000

\* Memory never overflows
MemorySafe == Len(mem) < 1000
```

### Пример 3: Корректность цикла

```tla
\* Loop counter is bounded
LoopBounded == 
    \A i \in DOMAIN mem : 
        mem[i] >= 0 /\ mem[i] <= 100
```

## ✅ Что можно проверить

### Автоматические проверки TLC

1. **Deadlock detection**
   - Программа не зависает
   - Все процессы завершаются

2. **Invariants**
   - Пользовательские условия
   - Безопасность памяти
   - Корректность результатов

3. **Temporal properties**
   - Liveness properties
   - Fairness conditions

4. **State space exploration**
   - Все возможные пути выполнения
   - Граничные случаи

### Примеры проверок

#### test_simple.c
```c
int main() {
    int a = 5;
    int b = 10;
    int c = a + b;
    return c;
}
```

**Инвариант:**
```tla
ResultIs15 == \E i \in DOMAIN mem : mem[i] = 15
```

**Результат:** ✓ Passed, ~15 states

#### test_loops.c
```c
int main() {
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += i;
    }
    return sum;
}
```

**Инвариант:**
```tla
SumCorrect == \E i \in DOMAIN mem : mem[i] = 10
```

**Результат:** ✓ Passed, ~50 states

## 🐛 Частые проблемы и решения

### Проблема 1: "Module Bitwise not found"

**Причина:** Используются битовые операции

**Решение:**
```bash
git clone https://github.com/tlaplus/CommunityModules.git
# В Toolbox: File → Preferences → Add library path
```

### Проблема 2: "Deadlock reached"

**Причина:** Программа не завершается корректно

**Решение:**
- Проверьте, что `main()` возвращает значение
- Проверьте условия циклов

### Проблема 3: "TLC ran out of memory"

**Решение:**
- Увеличьте память: `-Xmx8G`
- Уменьшите глубину поиска
- Упростите программу
