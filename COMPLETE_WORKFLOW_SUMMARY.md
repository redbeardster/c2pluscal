### 3️⃣ Ручная проверка в TLC

#### Процесс
```
1. Генерация TLA+ из C
   frama-c -pluscal tests/test_simple.c
   → test_simple.tla, test_simple.cfg

2. Трансляция PlusCal → TLA+
   java -cp ~/toolbox/tla2tools.jar pcal.trans test_simple.tla
   → Добавляет \* BEGIN TRANSLATION

3. Проверка с TLC model checker
   java -cp ~/toolbox/tla2tools.jar tlc2.TLC test_simple.tla
   → Model checking completed. No error has been found.
```
